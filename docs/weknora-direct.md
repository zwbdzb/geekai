# WeKnora 公共资料直连

1. 在 GeekAI「公共资料库 → 资料来源」填写用户设备可访问的 WeKnora 地址和 API Key。
2. 点击「测试并选择知识库」，选择需要赠送的库，设置名称并上架。后台保存远端知识库 ID。
3. ThinkBuddy 获取 `/api/v1/library` 中的地址、Key 和知识库 ID，自动调用现有手动添加方法，保存为账号的普通 WeKnora 连接。

客户端的文件查看、预览和检索均由原有 WeKnora 引擎直连处理。GeekAI 只管理连接和发放目录。来源 Key 原值保存在数据库，管理接口隐藏 Key；公开目录将 Key 下发给全部用户，因此应使用仅允许读取赠送知识库的 Key。

重复同步不会重复添加，手动连接保留用户自己的名称和 Key，自动添加的连接会更新下发凭据。移动后旧引用仍可用，删除后不会自动重建。下架或停用来源停止继续发放，已保存的连接保留；停止访问需在 WeKnora 撤销 Key。

本次不需要修改数据库。旧的客户端凭据和能力字段不再读取，保留原列即可。回滚应同时恢复 GeekAI 和 ThinkBuddy 版本；已下发的 Key 需要在 WeKnora 撤销才能停止使用。
